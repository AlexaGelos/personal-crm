# Группы контактов

## Why

Сейчас все контакты лежат одним списком по алфавиту. Людей из разных частей жизни (семья, друзья, теннис, коллеги-аналитики) не отделить друг от друга: нельзя быстро увидеть, с кем играешь в теннис, или понять, кому из семьи пора позвонить. Нужны группы, которые владелец заводит сам. Один человек может быть сразу в нескольких группах.

## What Changes

- Появляются группы контактов. Группы заводит сам владелец, с любыми названиями. После выкатки групп нет ни одной, ни у кого из контактов нет групп
- Контакт может входить в несколько групп сразу или ни в одну
- Страница «Группы»: список групп по алфавиту с числом контактов в каждой. На ней группу можно создать, переименовать и удалить. Название группы обязательно, не длиннее 50 символов. Двух групп с одинаковым названием быть не может, регистр букв и разница «ё» и «е» не важны: «Теннис» и «теннис», «Ёлка» и «Елка» считаются одной группой
- Удаление группы - с подтверждением. Контакты остаются, они только выходят из этой группы
- В формах «Добавить контакт» и «Изменить контакт» есть раздел «Группы»: все группы с галочками. Там же можно вписать новую группу: она сразу появляется с галочкой, а создаётся при сохранении контакта. Если нажать «Отмена», новой группы не будет
- В карточке контакта есть строка «Группы» с его группами. Каждая группа - ссылка на главную с этой группой
- На главной под заголовком ряд групп: «Все» и группы по алфавиту. Нажатие на группу оставляет в списке только её контакты. Одновременно выбрана одна группа. В конце ряда ссылка «Настроить группы» на страницу «Группы». Пока групп нет, в ряду только «Создать группу»
- Если выбрана группа:
  - поиск ищет только внутри неё
  - строка над списком («Показано 50 из 230», «Найдено: …») считает только контакты этой группы
  - «Показать ещё» добавляет контакты этой же группы
  - в блоке «Пора связаться» только просроченные из этой группы, число у заголовка тоже считает только их
- В строке списка контактов под именем видны группы контакта
- Тестовые контакты Данте (`pnpm db:seed:dante`) раскладываются по нескольким группам, кто-то сразу по нескольким. Скрипт добавляет группы и там, где контакты Данте уже загружены
- Тесты: в проекте появляется Vitest. Код фичи пишется по TDD: сначала тест, потом код. Тесты работы с базой идут на отдельной тестовой базе в том же локальном Postgres, без моков
- База данных: две новые таблицы - группы и связь «контакт - группа». Изменение только добавляет таблицы, существующие контакты и заметки не меняются

Не входит в эту фичу:

- e2e-тесты на Playwright и CI - отдельным изменением позже
- выбор нескольких групп в фильтре сразу
- поиск по названию группы в строке поиска
- цвета и значки групп, свой порядок групп (только по алфавиту)
- вложенные группы
- включение в группу одним нажатием из карточки или из списка, без формы
- макет экранов: экраны собираются в стиле приложения, проверка - на живом

## Capabilities

### New Capabilities

- `contact-groups`: группы контактов - создание, переименование и удаление групп, включение контакта в группы, группы в карточке и в списке, выбор группы на главной

### Modified Capabilities

- `keep-in-touch`: блок «Пора связаться» и число просроченных у его заголовка учитывают выбранную на главной группу

## Impact

- База данных: таблицы `groups` и `contact_groups` и миграция к ним. На сервере миграция применится сама при выкатке, до старта нового образа. Старый образ с новой базой работает: новых таблиц он просто не читает
- Новая страница `/groups`
- Главная: ряд групп, фильтр по группе в списке, поиске и блоке «Пора связаться», группы в строках списка
- Формы добавления и изменения контакта: раздел «Группы»
- Карточка контакта: строка «Группы»
- Тестовые данные: `pnpm db:seed:dante` создаёт группы
- Разработка: Vitest (есть в стеке в `CLAUDE.md`), команда `pnpm test`, тестовая база `<POSTGRES_DB>_test`. Новых строк в `.env` не нужно
- Новых библиотек для приложения и новых сервисов нет
